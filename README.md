# dev-snippets

Личная коллекция алгоритмов и утилитарных сниппетов на TypeScript — черновики для практики и подготовки к собеседованиям.

## Структура

- **`algorithms/`** — решения алгоритмических задач (поиск, работа с массивами, строками и т.д.)
  - `ARRAYS/` — задачи на массивы (`playlistDuration`, `shortestWord`, `topWords`)
  - `binary-search/` — бинарный поиск
  - `is-anagram/`, `is-fibonacci-sequence/`, `is-palindrome/`, `is-parenthesis-correct/` — задачи на проверки/предикаты
  - `line-search/`, `totalNumbers/` — прочие алгоритмические задачи
- **`snippets/`** — переиспользуемые утилиты
  - `debounce/`, `throttle/` — ограничение частоты вызовов
  - `retry/`, `rate-limit/` — устойчивость и контроль нагрузки
  - `promise-all/`, `promise-pool/` — работа с промисами
  - `queue/` — очередь

## Стек

TypeScript.
